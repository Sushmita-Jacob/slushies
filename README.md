# slushies
This is a weather information website made with Flask and deployed on Vercel (at https://slushies-murex.vercel.app/). The app uses openweatherapp.org's API keys to receive weather data on cities around the globe. Type in a city and country to find the temperature, humidity, and wind speed.

While this project was originally made for Hack Club's Slushies program, after some updates it was instead submitted to Hack Club: The Game. This is the first dynamic website I made and the first time I used a framework. I followed the Slushies "Getting Started" presentation slide tutorial to learn the basic structure of Flask and then added the weather feature after watching YouTube explanations. I also included scientific definitions on the main web page.

For my second ship, I updated my website based on the recommendations of my reviewer. First, since my app originally had little styling and was plain black and white, I added a light blue background and an animated cloud. Then, I had a validity check to make sure the site does not have an internal error if an invalid city or country was entered. Finally I privated my API key using an environmental variable. To whoever is reviewing this, lmk if you have more suggestions! :)
